# 充电机模拟器 使用说明

## 1. 工具用途

在没有充电机（电源模块）实物时，用电脑 + USB-RS485 模拟一台充电机，与 DTU 进行问答通信：

- 响应 DTU 的遥测、遥信查询
- 响应遥控命令
- 响应定值读写
- 内置电池模型，模拟 SOC/电压/告警随时间变化（默认运行）

工具只做通用 EB90 规约（通用充电机/版本 2 语义），一个串口、一台设备。

---



## 2. 快速开始（打包版）

1. 解压发布包，得到 `ChargerSim` 文件夹。
2. 双击 `ChargerSim.exe`。
3. 选择串口（USB-RS485 对应的 COM 口），波特率 9600。地址固定为 1，不需要设置。
4. 点 **“打开串口”**，顶部变成绿色 **“串口已打开”**。
5. 点 **“加载 XML...”**，选择与 DTU 配置一致的装置类型表。
6. 在“报文监视”里观察：
   - `RX`：DTU 发来的查询/控制
   - `TX`：工具回的应答
7. 左侧选择“遥测 / 遥信 / 遥控 / 定值”，查看和编辑对应数据。



## 3. 文件与配置

| 文件 | 用途 |
|---|---|
| `data/point_formats.json` | 点格式（运行时生成） |
| `data/battery_config.json` | 电池点值配置（运行时生成） |
| `data/preset*.json` | 预设值 |
| `data/frames*.txt` / `data/frames*.md` | 报文导出 |
| `data/events*.txt` | 运行日志导出 |

工具**不会修改**装置类型表 XML。
`data` 文件夹不需要预置，程序首次保存配置/导出时会自动创建在 exe 同级。

## 4. 常见问题

**Q：启动后定值一直是 `--`？**
没有收到 `0x1B` 读定值请求。等 DTU 轮询 `0x1B01`，或在报文监视里确认是否出现 `RX ... 1B 01`。

**Q：遥信/遥控为什么不能改？**
遥信表只读，要测试告警请用左侧“遥信模拟”；遥控是命令，表格只记录最后结果和时间，设备状态看遥信。

**Q：电池模型怎么启动？**
默认就在运行，没有启动/停止按钮。直接切换“交流供电”或 A/B/C 相失电即可。

**Q：电池参数里填了值，点表为什么没变？**
遥测要等 DTU 下一次 `0x01` 查询该组；定值要等下一次 `0x1B` 读取。保持默认值不会保存覆盖值，修改后才生效。

**Q：为什么没接线也有电压？**
点表是模拟器自己的状态。电池模型运行时会显示默认浮充电压；没接 DTU 只是不发报文。

**Q：报文监视没有内容？**
先确认串口已打开、A/B 接线正确、DTU 正在轮询。

**Q：exe 双击没反应？**
确认 exe 文件完整；安装 VC++ 运行库；检查杀毒软件是否拦截。

## 5. 源码运行 / 重新打包

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install PySide6==6.12.0
.venv\Scripts\python.exe -m app.main
```

自测：

```bat
.venv\Scripts\python.exe selftest.py
```

重新打包：

```bat
build_exe.bat
```

输出：

```
dist\ChargerSim\ChargerSim.exe
```
